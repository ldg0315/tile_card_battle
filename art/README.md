# 캐릭터 그림 넣는 법

이 폴더에 그림을 넣으면 게임이 자동으로 사용합니다. 그림이 없는 동작은 코드로 만든 임시 도트(`scripts/pixel_art.gd`)가 대신 나옵니다. 동작 하나씩 넣어가며 확인해도 됩니다.

## 파일 위치와 이름

```
art/<캐릭터id>/<동작>_<프레임수>.png
```

- 캐릭터 id는 `scripts/cards.gd`의 키(`sword`, `archer`)와 같아야 합니다.
- 동작은 `idle`(대기), `walk`(이동), `attack`(공격), `hit`(피격), `guard`(방어), `die`(쓰러짐) 여섯 가지입니다. `die`는 마지막 프레임에서 멈춘 뒤 서서히 사라집니다.
- 예: `art/sword/attack_4.png`는 검사 공격 동작 4프레임입니다.
- 프레임 수를 생략하면(`idle.png`) 한 장짜리로 봅니다.

## 그림 규칙

- 프레임을 **가로 한 줄로 같은 폭**으로 이어 붙입니다(스프라이트 시트 가로 스트립).
- 캐릭터는 **오른쪽을 보게** 그립니다. 왼쪽은 게임이 좌우 반전합니다.
- **몸 중심은 프레임 가로 가운데, 발은 맨 아래 줄**에 둡니다. 어긋나면 좌우 반전할 때 몸이 옆으로 튑니다.
- 배경은 투명으로 둡니다.
- 한 캐릭터의 동작은 **모두 같은 프레임 크기**로 맞춥니다. 크기는 `idle` 첫 프레임 높이를 기준으로 화면에서 같은 키(2.16)가 되게 맞춰지므로, 다른 동작의 크기가 다르면 그 동작만 커지거나 작아집니다.
- 추천 크기는 48×64 안팎입니다. 칼이나 활이 앞으로 뻗는 동작이 있다면 폭을 넉넉히 잡으세요.

## Aseprite에서 내보내기

`File → Export Sprite Sheet`에서 Layout을 **Horizontal Strip**으로 두고, 동작(태그)별로 따로 내보낸 뒤 위 이름 규칙대로 저장합니다.

## 확인

에디터를 열지 않아도 게임만 실행하면 새 그림이 보입니다. 임시 도트 전체는 아래 명령으로 한 장에 모아 볼 수 있습니다.

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path ~/tile_card_battle -s tools/dump_pixel_art.gd -- ~/tile_card_battle/shots/pixel_art.png
```
